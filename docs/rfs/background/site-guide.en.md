# What to Find on This Site

This training covers the GEOGLOWS River Forecast System (RFS): how the model works, the data it produces, and the tools for viewing and
downloading that data. If you have used version 2 of RFS, start with [What's New?](../whats-new.md), which summarizes the main changes in
version 3.

**Part 1, Background,** introduces the model. The [Model Overview](model-overview.md) explains how RFS predicts the amount of water in rivers
around the world, and this page describes what the rest of the training covers.

**Part 2, Model Formulation,** explains how the model works: [an overview](../model-formulation/model-formulation.md) of the system,
[the model inputs](../model-formulation/model-inputs.md), [river routing](../model-formulation/river-routing.md),
and [flood mapping](../model-formulation/flood-mapping.md). If you are mainly interested in using the data, you can skip this part.

**Part 3, Data,** describes [the data RFS produces](../data/available-data.md), including the retrospective simulation, the 15-day forecasts,
and the flood maps, and how to get it: through [the datastore](../data/accessing-data/datastore.md),
[advanced accessing methods](../data/accessing-data/advanced-methods.md), and [accessing flood maps](../data/accessing-data/flood-maps.md).

**Part 4, Globally Available Web Applications,** introduces [the web applications](../web-apps/overview.md) that let you view and download RFS
data without writing code, and walks through [the Hydroviewer](../web-apps/hydroviewer.md) in detail.

**Part 5, Tutorials,** works through common tasks step by step: [finding river numbers](../tutorials/find-river-numbers.md),
[adding the RFS web map layers to a GIS](../tutorials/web-map.md), and [calculating streamflow volume](../tutorials/streamflow-volume.md).

**Webinars** are recordings of the GEOGLOWS training webinars, starting with
[the history of GEOGLOWS and an introduction to RFS](../webinars/rfs-v2-webinar-1.md). They were made for version 2 of the model, but many of the
concepts still apply.

**Publications** lists [the research papers and reports](../../publications.md) about RFS and how it has been used.
