# Web Applications

One way to visualize, download, and interact with the RFS data is through a series of web applications available through [apps.geoglows.org](https://apps.geoglows.org). Each of these applications has a specific audience and purpose. They are all driven through the RFS data and represent one way that the data could be used. Further applications and customizations are possible if users download and use the data themselves from the datastore.  Each of the web applications provide specific visualization and interpretation for the data, which can make it faster and easier to use the data. An overview of the applications is given here, and then each application has its own page where you can find more detailed information and user instructions.

## 1. The Hydroviewer

- **Link:** [https://apps.geoglows.org/rfs](https://apps.geoglows.org/rfs#lon=10.00&lat=18.00&zoom=3.00&definition=)
- **Main Purpose:** Provide easy data visualizations and downloads
- **Target Audience:** Technical users who would like to be able to quickly visualize data on some of their streams of interest.

![The Hydroviewer web application](../../static/images/hydroviewer-app.png)

## 2. FEWS (Flood Early Warning System)

- **Link:** [https://apps.geoglows.org/previews/fews4all](https://apps.geoglows.org/previews/fews4all)
- **Main Purpose:** Provide flood warnings
- **Target Audience:** Non-technical users who may want to see if they are going to experience a flood without downloading the data themselves.

![The FEWS4All web application](../../static/images/fews-app.png)

## 3. HydroSOS

- **Link:** [https://apps.geoglows.org/hydrosos](https://apps.geoglows.org/hydrosos)
- **Main Purpose:** Display the HydroSOS categories according to the WMO’s protocol
- **Target Audience:** Users with the WMO

![The HydroSOS Water Monitor web application](../../static/images/hydrosos-app.png)
