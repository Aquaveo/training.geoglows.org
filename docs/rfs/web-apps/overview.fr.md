# Applications Web

Une façon de visualiser, de télécharger et d'interagir avec les données du RFS consiste à utiliser une série d'applications web disponibles sur [apps.geoglows.org](https://apps.geoglows.org). Chacune de ces applications a un public et un objectif spécifiques. Elles sont toutes alimentées par les données du RFS et représentent une manière possible d'utiliser ces données. D'autres applications et personnalisations sont possibles si les utilisateurs téléchargent et utilisent eux-mêmes les données depuis le magasin de données. Chacune des applications web offre une visualisation et une interprétation spécifiques des données, ce qui peut rendre leur utilisation plus rapide et plus simple. Un aperçu des applications est présenté ici, puis chaque application dispose de sa propre page où vous trouverez des informations plus détaillées et des instructions d'utilisation.

## 1. Le Hydroviewer

- **Lien :** [https://apps.geoglows.org/rfs](https://apps.geoglows.org/rfs#lon=10.00&lat=18.00&zoom=3.00&definition=)
- **Objectif principal :** Fournir des visualisations et des téléchargements de données simples
- **Public cible :** Utilisateurs techniques souhaitant pouvoir visualiser rapidement les données de certains cours d'eau qui les intéressent.

![L'application web Hydroviewer](../../static/images/hydroviewer-app.png)

## 2. FEWS (Système d'Alerte Précoce aux Inondations)

- **Lien :** [https://apps.geoglows.org/previews/fews4all](https://apps.geoglows.org/previews/fews4all)
- **Objectif principal :** Fournir des alertes aux inondations
- **Public cible :** Utilisateurs non techniques qui souhaitent savoir s'ils risquent de subir une inondation sans télécharger eux-mêmes les données.

![L'application web FEWS4All](../../static/images/fews-app.png)

## 3. HydroSOS

- **Lien :** [https://apps.geoglows.org/hydrosos](https://apps.geoglows.org/hydrosos)
- **Objectif principal :** Afficher les catégories HydroSOS selon le protocole de l'OMM
- **Public cible :** Utilisateurs de l'OMM

![L'application web HydroSOS Water Monitor](../../static/images/hydrosos-app.png)
